# ChargedLife Pre-Alpha 1.0.56

## Dashboard redesign
- Rebuilt the main dashboard into a simpler, cleaner one-page layout.
- Removed the oversized dashboard sections and reduced empty space.
- Kept all core dashboard information on a single page without forcing a zoomed-out feel.
- Replaced the previous business overview block with a cleaner Business Portfolio table.
- Added a more useful Today panel with a dynamic opening-progress callout for early-game businesses.
- Kept Top Earning Businesses and Performance Snapshot, but redesigned both into more compact cards.
- Reworked Recommended Actions into clearer, easier-to-read action cards.

## New-player flow
- Preserved the company onboarding flow where players create their company first and then choose their first business.
- Kept Fast Food as the only available starting industry for now.

## Cleanup
- Removed the restaurant artwork from the dashboard so the page feels cleaner and less cluttered.
- Updated the visible game version and save version handling to 1.0.56.
