# ChargedLife Pre-Alpha 1.0.56 Testing

## Test focus
1. Open the game and confirm the dashboard fits naturally on one page on a standard desktop viewport.
2. Confirm the dashboard no longer shows restaurant building artwork.
3. Verify the Business Portfolio panel renders correctly with one active business.
4. Verify the Today panel shows opening progress before the restaurant is opened.
5. Verify the Today panel shows upcoming events and recent activity.
6. Verify Top Earning Businesses and Performance Snapshot render as compact cards.
7. Verify Recommended Actions render as a readable grid.
8. Confirm version text shows Pre-Alpha 1.0.56.
9. Run `npm run verify:v1056`.
10. Run a full `npm run build`.
